# Documentação de Funcionalidades e Sugestão de Atalhos do Editor de Texto

Esta documentação lista todos os recursos, botões e funcionalidades disponíveis atualmente no editor de texto e propõe atalhos de teclado intuitivos e baseados em padrões de mercado para melhorar a acessibilidade e a eficiência do usuário.

## 1. Ações Principais de Arquivo e Controle do Editor

| Funcionalidade | Descrição | Sugestão de Atalho | Observação |
| :--- | :--- | :--- | :--- |
| **Desfazer** (Undo) | Desfaz a última alteração realizada no texto. | `Ctrl + Z` | Padrão universal. |
| **Refazer** (Redo) | Refaz a última alteração desfeita. | `Ctrl + Y` ou `Ctrl + Shift + Z` | Padrão universal. |
| **Salvar Documento** (Save) | Salva o documento atual no servidor / banco de dados. | `Ctrl + S` | Padrão universal. |
| **Rascunhos** (Drafts) | Salva um rascunho local ou remoto do texto. | `Ctrl + Shift + S` | Padrão comum para "Salvar Como" ou rascunho em editores modernos. |
| **Meus Documentos** | Abre a barra ou modal com os documentos salvos do usuário. | `Ctrl + O` | Padrão universal para "Open" (Abrir documento). |
| **Copiar Tudo** | Copia todo o conteúdo do editor para a área de transferência. | `Ctrl + Shift + C` | Facilita a exportação rápida do conteúdo. |
| **Limpar Editor** | Remove todo o texto e formatação inseridos no editor. | `Ctrl + Shift + Delete` | Evita exclusões acidentais garantindo que seja um atalho complexo. |
| **Importar PDF** | Importa o conteúdo de um arquivo PDF para o editor. | `Ctrl + Shift + I` | `I` para Import. |
| **Exportar** | Exporta o texto atual (para PDF, DOCX, TXT, etc.). | `Ctrl + P` ou `Ctrl + E` | `P` atende ao "Print/PDF" e `E` para Export. |
| **Pré-visualizar** | Mostra como o documento ficará no formato final de leitura/post. | `Ctrl + Shift + P` | Padrão para "Preview". |
| **Configurações** | Abre as configurações da barra de ferramentas e do editor. | `Ctrl + ,` | Padrão onipresente em editores de código e IDEs (como VSCode). |
| **Reescrever com IA** | Aciona o assistente de IA para reescrever ou melhorar o texto selecionado. | `Ctrl + J` ou `Ctrl + Espaço` | `Ctrl + J` é bastante utilizado em ferramentas de IA (como Notion AI). |

## 2. Formatação de Texto (Nível de Caractere)

| Funcionalidade | Descrição | Sugestão de Atalho | Observação |
| :--- | :--- | :--- | :--- |
| **Negrito** (Bold) | Aplica peso extra ao texto. | `Ctrl + B` | Padrão universal. |
| **Itálico** (Italic) | Aplica estilo itálico ao texto. | `Ctrl + I` | Padrão universal. |
| **Sublinhado** (Underline) | Adiciona uma linha abaixo do texto. | `Ctrl + U` | Padrão universal. |
| **Tachado** (Strikethrough) | Adiciona um risco ao meio do texto. | `Ctrl + Shift + X` | Comum em editores como Google Docs/Word. |
| **Código Inline** (Code) | Formata o texto como trecho de código. | `Ctrl + E` | Atalho comum; alternativamente utilizar backticks ( \` ). |
| **Subscrito** (Subscript) | Posiciona o texto abaixo da linha (ex: H₂O). | `Ctrl + =` | Padrão do Microsoft Word. |
| **Sobrescrito** (Superscript) | Posiciona o texto acima da linha (ex: X²). | `Ctrl + Shift + +` | Padrão do Microsoft Word. |
| **Cor do Texto** | Altera a cor dos caracteres selecionados. | - | Acesso geralmente feito por clique, atalho pode não ser produtivo. |
| **Cor de Fundo** (Highlight) | Adiciona marca-texto/fundo ao texto selecionado. | `Ctrl + Shift + H` | `H` para Highlight. |
| **Limpar Formatação** | Remove negrito, itálico, cores, etc., da seleção. | `Ctrl + \` | Padrão utilizado no Google Docs. |

## 3. Formatação de Parágrafo e Estrutura

| Funcionalidade | Descrição | Sugestão de Atalho | Observação |
| :--- | :--- | :--- | :--- |
| **Cabeçalhos** (H1 a H6) | Transforma o parágrafo em um título do nível escolhido. | `Ctrl + Alt + [1-6]` | Padrão do Google Docs e Word. |
| **Alinhar à Esquerda** | Alinha o texto na margem esquerda. | `Ctrl + Shift + L` | `L` para Left. Padrão universal. |
| **Centralizar** | Alinha o texto ao centro da página. | `Ctrl + Shift + E` | `E` (ou C se disponível). Padrão em editores (Word usa E). |
| **Alinhar à Direita** | Alinha o texto na margem direita. | `Ctrl + Shift + R` | `R` para Right. Padrão universal. |
| **Justificar** | Preenche uniformemente o texto entre as margens. | `Ctrl + Shift + J` | `J` para Justify. Padrão universal. |
| **Lista com Marcadores** | Cria uma lista não ordenada (pontos). | `Ctrl + Shift + 8` | Atalho semelhante ao Word/Docs. Alternativamente: começar com `*` + Espaço. |
| **Lista Numerada** | Cria uma lista ordenada (1, 2, 3...). | `Ctrl + Shift + 7` | Atalho semelhante ao Word/Docs. Alternativamente: começar com `1.` + Espaço. |
| **Bloco de Citação** | Transforma o parágrafo em uma citação (Blockquote). | `Ctrl + Shift + 9` | Alternativa com Markdown: começar com `>` + Espaço. |
| **Espaçamento de Linhas** | Ajusta o espaço vertical no parágrafo. | - | Ação mais visual, manter acesso via clique é recomendado. |
| **Fonte e Tamanho da Fonte**| Altera a tipografia e o tamanho do texto. | `Ctrl + Shift + . / ,` | Usar `>` (Aumentar) e `<` (Diminuir) para ajustar tamanho rapidamente. |

## 4. Inserção de Elementos Diversos

| Funcionalidade | Descrição | Sugestão de Atalho | Observação |
| :--- | :--- | :--- | :--- |
| **Inserir Link** | Transforma o texto selecionado em um hiperlink. | `Ctrl + K` | Padrão universal. |
| **Inserir Imagem** | Abre a modal para upload/seleção de imagens. | `Ctrl + Alt + I` | `I` para Image. |
| **Inserir Tabela** | Cria e manipula uma estrutura de tabela. | `Ctrl + Alt + T` | `T` para Table. |
| **Bloco de Código** | Insere um contêiner multilinhas para digitação de código. | `Ctrl + Alt + C` | Alternativa com Markdown: começar um parágrafo com ` ``` `. |
| **Inserir Youtube** | Anexa um frame de vídeo do Youtube pelo link. | - | Geralmente não necessita de atalho pela baixa frequência de uso. |

## 5. Ferramentas de Revisão e Idioma

| Funcionalidade | Descrição | Sugestão de Atalho | Observação |
| :--- | :--- | :--- | :--- |
| **LanguageTool Toggle** | Ativa ou desativa a verificação gramatical na tela. | `F7` | Tecla padrão para "Verificação Ortográfica/Gramatical" (Word). |
| **LanguageTool Sidebar** | Abre os detalhes e painel principal do corretor. | `Shift + F7` | Acessa o dicionário e painel avançado (Word). |
| **Spellcheck do Navegador**| Alterna o corretor nativo do navegador (BrowserSpellcheck). | - | Frequência de alteração baixa durante o uso. |

---

> **Observação sobre a Tabela de Atalhos**:
> O uso e prioridade entre atalhos devem sempre verificar conflitos com navegadores e garantir que em ambientes Mac OS o `Ctrl` se comporte como `Cmd` (⌘) para fins de conforto do usuário. Esta configuração de binds proporcionará uma curva de aprendizado rápida aos usuários vindos do Google Docs e Microsoft Word.
